## 建站主机 DC2：最低 ¥0.99/月，走 Cloudflare CDN

DC2 这条线路主打一个"便宜"。母机是年付 OVH 服务器，稳定性有一定保障（卖家原话：不用担心跑路），用的是 aaPanel（宝塔国际版），走 CNAME 解析接 Cloudflare CDN。

需要注意：**DC2 没有大陆访问优化**，国内直连速度一般。如果你的目标用户主要在国内，优先选 DC1 US；如果你的站面向海外或者套 CF 就够用，DC2 性价比更高。

## 这家店适合谁？

**适合的场景：**
- 个人博客、轻量工具站、测试环境
- 预算极低但又想要有中美直连线路的用户
- 需要多站部署的开发者（数据库和站点数量不限）
- 已经有 Cloudflare 使用习惯的用户（DC2 更合适）

**不太适合的场景：**
- 大流量商业站（月流量上限较低）
- 对大陆速度要求极高的生产环境（可以考虑 DC1 US，但 DC2 不建议）
- 不会自己配置面板的新手（HestiaCP / aaPanel 需要一定上手成本）
